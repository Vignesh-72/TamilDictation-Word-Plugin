## Overview

**Tamil Dictation** is a Microsoft Word Task Pane Add-in that enables native speakers, government officials, and content creators to dictate directly in Tamil or English — right inside Word. It uses the browser's Web Speech API for voice recognition and the Office.js API to write text precisely at the cursor position, with no copy-paste needed.

The add-in runs locally via a development server and is sideloaded into Word using a `manifest.xml` file — meaning there is no standalone application to install. It runs entirely inside Word's task pane panel, served from your local machine.

---

## Features

**Dual-Language Dictation** — Dictate in Tamil (`ta-IN`) or English (`en-IN`). Switch languages on the fly from within the task pane without restarting Word.

**Smart Punctuation Engine** — Speak natural Tamil punctuation commands and the add-in inserts the correct symbols automatically. No need to manually type punctuation marks.

**Real-Time Translation** — Dictate in Tamil and have it typed in English inside the document, or vice versa. The translation layer works inline as you speak.

**Government Standard Typography** — Text is injected using the `TAU-Marutham` font, the official Tamil typography standard used across Tamil Nadu government documents.

**Native Word Integration** — Runs as a Fluent UI Task Pane inside Word's ribbon. Maintains full document context including cursor position and paragraph formatting.

**Offline-Ready Architecture** — Core dictation runs via the Web Speech API in the browser engine; no external speech service is required for recognition.

## Prerequisites

Before you begin, make sure the following are installed on your machine:

- [Node.js](https://nodejs.org/) v16 or higher (check with `node -v`)
- npm v8 or higher (bundled with Node.js)
- Microsoft Word — Desktop (Windows/macOS) or Word on the Web
- A modern browser with Web Speech API support (Chrome is recommended for `SpeechRecognition`)

> **Note on browser support:** The Web Speech API is currently best supported in Chromium-based browsers. When running in Word Desktop, the embedded WebView2 runtime handles this. Word on the Web works best in Microsoft Edge or Chrome.

## Local Development

If you want to edit the React code, change colors, or add new features, you need to run the local development server. This serves the add-in from your own machine at `https://localhost:3000` and lets you see changes instantly every time you save a file.

### Step 1 — Clone the repository

```bash
git clone https://github.com/Vignesh-72/TamilDictation-Word-Plugin.git
```

### Step 2 — Navigate to the project folder

Open your Terminal (Command Prompt or VS Code Terminal) and navigate into the project:

```bash
cd path/to/your/tamil-dictation-folder
```

### Step 3 — Install dependencies

```bash
npm install
```

### Step 4 — Trust the local HTTPS certificate

Office Add-ins require HTTPS even on localhost. Run this once to install a trusted dev certificate so Word doesn't show security warnings:

```bash
npx office-addin-dev-certs install
```

### Step 5 — Start the local server

```bash
npm start
```

This starts your app at `https://localhost:3000`. Keep this terminal window open while you're developing — the server must stay running for the add-in to work inside Word.

### Step 6 — Sideload into Word

1. Open **Microsoft Word** (Desktop or Web).
2. Go to **Insert → Add-ins → My Add-ins**.
3. Click **Upload My Add-in** and select the `manifest.xml` file from your project folder.
4. The **Tamil Dictation** button will appear in the **Home** tab ribbon.

You will now see your live code changes instantly each time you save a file — no need to reload Word.

> **Tip:** Use VS Code with the project folder open. Changes to any file in `src/` will automatically rebuild and refresh the task pane.

## Building for Production

When you are ready to host the add-in online (e.g., on Netlify, Vercel, or GitHub Pages), run:

```bash
npm run build
```

Webpack bundles all source files into the `dist/` folder with minification and chunk splitting. Upload the contents of `dist/` to your hosting provider of choice.

Before sharing your `manifest.xml`, update every URL inside it to point at your live hosted domain instead of `localhost`:

```xml
<!-- Replace localhost URLs with your live domain -->
<SourceLocation DefaultValue="https://your-live-domain.com/taskpane.html"/>
<bt:Url id="Commands.Url" DefaultValue="https://your-live-domain.com/commands.html"/>
<bt:Url id="Taskpane.Url"  DefaultValue="https://your-live-domain.com/taskpane.html"/>
```

> The `dist/` folder is git-ignored by default. Commit it only if your hosting service does not support build pipelines.

## Installing the Add-in in Word

Once your add-in is hosted (either locally or on Netlify), sideload it into Word using the `manifest.xml` file.

### Word on the Web

1. Open [Word on the Web](https://www.office.com/launch/word) and open any document.
2. Go to **Insert → Add-ins → Upload My Add-in**.
3. Select `manifest.xml` from this repository.
4. Click **Tamil Dictation** in the **Home** tab ribbon to open the task pane.

### Word Desktop (Windows)

1. Open any Word document.
2. Go to **Insert → Get Add-ins → My Add-ins → Upload My Add-in**.
3. Select `manifest.xml`.
4. The **Tamil Dictation** button will appear in the **Home** tab under the **Dictation** group.

### Word Desktop (macOS)

1. Open Word and go to **Insert → Add-ins**.
2. Select **Upload My Add-in** and choose `manifest.xml`.

> After sideloading, the add-in persists in Word until you explicitly remove it. To update, re-upload the manifest or clear the add-in cache.

## Voice Command Reference

Speak these commands in Tamil while dictating to control punctuation and formatting. The add-in maps them to the correct symbols before inserting text into the document.

| Spoken Command (Tamil) | Action | Symbol / Output |
|---|---|---|
| முற்றுப்புள்ளி | Full Stop | `.` |
| கேள்விக்குறி | Question Mark | `?` |
| ஆச்சரியக்குறி | Exclamation Mark | `!` |
| காற்புள்ளி | Comma | `,` |
| மேற்கோள் குறி | Quotation Mark | `"` |
| புதிய வரி | New Line / Paragraph Break | `↵` (Enter) |
| இடைவெளி | Space | ` ` |
| நிறுத்துக | Stop Dictation | Stops recognition |

> Additional voice shortcuts can be configured inside the **Settings** tab within the add-in task pane.
